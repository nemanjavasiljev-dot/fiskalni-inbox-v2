# FiscalBox V5.8.1 — mobilni naziv kompanije

Na mobilnoj verziji naziv aktivne kompanije je sada diskretniji i konzistentan kroz aplikaciju.

- veličina naziva kompanije: 23 px na ekranima do 650 px
- naziv je i dalje odmah ispod glavnog headera stranice
- dugi nazivi se pravilno prelamaju bez prevelikog zauzimanja ekrana
- promena je primenjena na Dashboard, Fajlove, Pretplatu, prikaz klijenta i podešavanja knjigovodstvene agencije
- desktop prikaz ostaje nepromenjen

Nema SQL migracije za ovu verziju.
