# FiscalBox V5.8.2 — kompanijski meni u zaglavlju

- Dugme Odjava je uklonjeno iz desnog ugla glavnog USER/FIRMA zaglavlja.
- U desnom uglu se prikazuju logo i naziv aktivne kompanije.
- Dodir/klik na logo ili naziv otvara meni sa: Podešavanja kompanije, Podešavanja korisnika i Izloguj se.
- Dodata je stranica `/app/settings` sa odvojenim podešavanjima kompanije i korisnika.
- Podešavanja kompanije omogućavaju izmenu kontakt emaila i telefona; registarski podaci ostaju zaključani.
- Podešavanja korisnika omogućavaju izmenu imena/prezimena i lozinke.
- Mobilni prikaz je kompaktan i naziv firme se skraćuje/prelama bez širenja headera.
- Kompanijski meni je postavljen i na USER stranice Fajlovi, Pretplata, Moji računi i Podešavanja.
