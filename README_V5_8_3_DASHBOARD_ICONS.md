# FiscalBox V5.8.3 — USER dashboard u ikonama

- U USER/FIRMA modu uklonjen je duplirani blok sa logoom, nazivom firme i oznakom FIRMA ispod headera.
- Identitet firme ostaje samo u gornjem desnom CompanyHeaderMenu meniju.
- Oslobođeni prostor sada koristi kompaktan dashboard sa ikonama: Računi, Troškovi, PDV i Čeka slanje.
- Na mobilnom dashboard je 2x2 radi čitljivosti, na širim ekranima 4 u redu.
- Stare velike KPI kartice su uklonjene samo za USER/FIRMA mod da se podaci ne dupliraju.
- Dugme Pošalji knjigovođi ostaje odmah ispod dashboarda.
