# FiscalBox V5.9.2.3 — prijem od poslednje sinhronizacije

- Na KNJIGO dashboardu, odmah ispod kartica **Novi dokumenti** i **Novi računi**, dodata su dva velika prozora:
  - **Preuzmi fiskalne**
  - **Preuzmi dokumenta**
- Veliki broj **Novi računi / Novi dokumenti** sada uvek predstavlja sve neraspoređene stavke pristigle od poslednje sinhronizacije, nezavisno od filtera „Tekući mesec / Ukupno“.
- Klik na sinhronizaciju obrađuje sve novo, automatski raspoređuje stavke odgovarajućim klijentima i zatim prikazuje poruku **Baza je ažurirana**.
- U svakom velikom prozoru prikazuje se vreme poslednje uspešne sinhronizacije izvedeno iz poslednje raspoređene stavke.
- Preuzimanje PDF-a i štampa i dalje se rade unutar konkretnog klijenta.

Nema nove SQL migracije.
